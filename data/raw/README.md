
   # Raw Data

   The original raw dataset is not included in this repository due to file size.

   **Source:** [Indian Job Market Dataset 2025-2026 (Kaggle)](https://www.kaggle.com/datasets/shivamshrivastava21/indian-job-market-dataset-2025-2026)

   To reproduce this project:
   1. Download the dataset from the Kaggle link above
   2. Place the extracted file in this folder (`data/raw/`)
   3. Run the notebook in `python/data_cleaning.ipynb`
